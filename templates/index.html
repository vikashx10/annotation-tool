Instructions:

  • Load Next PDF: Click to load the next unprocessed PDF from your local directory
  • Click on a bounding box to remove it (when Draw Mode is OFF)
  • Enable Draw Mode and drag to draw a new bounding box around a layout element
  • Select a class from the popup (Header, Footer, Table, etc.)
  • Clear Region removes all annotations within the selected area
  • Use Previous/Next buttons to navigate between pages
  • Click Save Changes to save annotations for the current page
  • Click Finish PDF when done with all pages - marks as processed and loads next PDF
  • Keyboard shortcuts: Left/Right: Previous/Next | Home/End: First/Last | S: Save & Next | D: Toggle Draw Mode
